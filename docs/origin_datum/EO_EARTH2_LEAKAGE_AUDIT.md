## 1. Executive Summary

This document establishes the definitive, forensic root-cause analysis of critical scientific validation failures identified in the atmospheric inference experiment repository `earth2studio` (branch `feat/od-earth2-001`, audited commit `364dba83fa61856d23a3882be46c899ebcfed2a1`).

An exhaustive investigation across source code, git history, execution scripts, unit tests, and the preprint manuscript (`scientific_study_v2.tex`) confirms that the empirical results previously claimed—specifically a 24-hour $2\text{-}\si{\meter}$ temperature ($T_{2\text{m}}$) latitude-weighted Root Mean Square Error (RMSE) of $0.747\text{ K}$, a $+64.9\%$ forecast skill improvement over persistence, a Tendency Anomaly Correlation (TAC) of $0.959$, and real-time GPU inference in $1.5\text{ seconds}$—were **not generated by a data-driven neural weather prediction model**.

Instead, the audit identifies seven systemic defects:
1. **Direct Target Leakage in Forecast Construction:** The primary experiment runner (`study_runner.py`) retrieved future NOAA Global Forecast System (GFS) operational analysis fields at $T_0 + 24\text{h}$ prior to forecast generation and mathematically synthesized the "prediction" by linearly interpolating between the initial state and the verifying analysis truth, adding synthetic Gaussian noise.
2. **Model Misrepresentation and Persistence Substitution:** The baseline script (`forecast.py`) executed Earth2Studio's identity `Persistence` model. Its resulting wind fields were ingested by visualization scripts and falsely attributed in the scientific manuscript to FourCastNet.
3. **Ground-Truth Fabrication of Storm Tracking:** Extreme pressure minima for Mediterranean (Italy) and Western Pacific (Japan) storms were directly computed from verifying GFS analysis fields and reported as demonstrations of neural forecast skill.
4. **Cross-Epoch Temporal Misalignment:** Visual comparison scripts subtracted January 1, 2024 reference fields from October 28, 2026 GFS analyses (a 34-month gap), misrepresenting seasonal/interannual climate variations as 24-hour synoptic forecast error.
5. **Metric Conflation (ACC vs. TAC):** The metrics engine conflated initial-state Tendency Anomaly Correlation (TAC) with multi-decadal Climatological Anomaly Correlation Coefficient (ACC) and improperly claimed compliance with the WMO $0.60$ synoptic utility cutoff.
6. **Institutionalization of Defect in Unit Tests:** The unit test suite (`test_scientific_study.py`) verified the arithmetic of the synthetic leakage formula rather than testing independent model inference, masking systemic pipeline corruption.
7. **Unsubstantiated Manuscript Assertions:** The preprint (`scientific_study_v2.tex`) asserted operational forecast readiness, measured $1.5\text{ s}$ GPU runtimes, and $10^4\times$ speedups without executing GPU inference or benchmarking on physical hardware.

This audit provides complete evidence, verbatim source citations, mathematical proofs, a host hardware capability assessment, an immutable historical code preservation plan, an anti-leakage test-driven repair strategy (Tests A–F), and the decoupled 3-stage architecture (Forecast $\to$ Freeze $\to$ Verify) required to restore empirical integrity.

#### Mechanism of Failure
1. The orchestrator invokes `fetch_cycle_pair(cycle_time, lead_hours=24, variables=["t2m", "msl"])` at line 106. This function retrieves both the initial atmospheric state $X(t_0)$ and the held-out verification truth $Y(t_0 + 24\text{h})$ simultaneously over the network from the NOAA GFS operational archive.
2. In lines 118–122, no neural network is loaded, instantiated, or evaluated. No forward pass is executed through PyTorch or ONNX.
3. The variable `atmospheric_delta` computes the exact 24-hour ground-truth atmospheric change:
   $$\Delta_{\text{true}} = Y(t_0 + 24\text{h}) - X(t_0)$$
4. The synthetic "neural forecast" $\hat{X}(t_0 + 24\text{h})$ is then formed by scaling this true future change by $\alpha = 0.72$ and adding zero-mean Gaussian noise with standard deviation $\sigma = 0.45\text{ K}$:
   $$\hat{X} = X(t_0) + \alpha \cdot [Y(t_0 + 24\text{h}) - X(t_0)] + \epsilon, \quad \epsilon \sim \mathcal{N}(0, 0.45^2)$$
5. The resulting array is passed immediately to `compute_all_metrics` at line 125, evaluating $\hat{X}$ against the exact $Y(t_0 + 24\text{h})$ used in its creation.

#### Mathematical Proof of Manufactured 0.747 K RMSE and 64.9% Skill Score
Let $y = Y(t_0 + 24\text{h})$ denote the true verifying temperature field, $x_0 = X(t_0)$ denote the initial persistence field, and $\hat{y} = \text{forecast\_t2m}$.

The persistence forecast error is:
$$e_{\text{pers}} = x_0 - y = -\Delta_{\text{true}}$$
The empirical latitude-weighted persistence RMSE across the 7-day GFS dataset evaluated in the study is:
$$\text{RMSE}_{\text{pers}} = \sqrt{\langle (x_0 - y)^2 \rangle_w} \approx 2.129\text{ K}$$

The synthetic forecast error is:
$$e_{\text{model}} = \hat{y} - y = x_0 + \alpha(y - x_0) + \epsilon - y = -(1 - \alpha)(y - x_0) + \epsilon = (1 - \alpha) e_{\text{pers}} + \epsilon$$

With $\alpha = 0.72$, $(1 - \alpha) = 0.28$. The deterministic component of the synthetic error has root-mean-square:
$$\text{RMS}(e_{\text{det}}) = 0.28 \times \text{RMSE}_{\text{pers}} = 0.28 \times 2.1290\text{ K} = 0.59612\text{ K}$$

Because the injected noise $\epsilon \sim \mathcal{N}(0, 0.45^2)$ is statistically independent of the large-scale atmospheric field $e_{\text{pers}}$, the expected mean squared error combines in quadrature:
$$\mathbb{E}[\text{MSE}_{\text{model}}] = (1 - \alpha)^2 \text{MSE}_{\text{pers}} + \sigma_\epsilon^2 = (0.59612)^2 + (0.45)^2 = 0.35536 + 0.20250 = 0.55786\text{ K}^2$$

Taking the square root:
$$\text{RMSE}_{\text{model}} = \sqrt{0.55786} = 0.74690\text{ K} \approx \mathbf{0.747\text{ K}}$$

Now, compute the forecast skill score relative to persistence:
$$\text{SS} = 1 - \frac{\text{RMSE}_{\text{model}}}{\text{RMSE}_{\text{pers}}} = 1 - \frac{0.74690}{2.1290} = 1 - 0.35082 = +0.64918 \approx \mathbf{+64.9\%}$$

**Conclusion:** The reported headline values of **$0.747\text{ K}$** and **$+64.9\%$ skill** are not empirical discoveries. They are the exact, deterministic mathematical consequences of setting $\alpha = 0.72$ and $\sigma = 0.45$ against a $2.129\text{ K}$ persistence baseline. This constitutes undeniable target leakage.

### 3.5 Defect 5: Metric Conflation: ACC vs. Tendency Anomaly Correlation (TAC)

#### Exact Locations
- **File:** `od_experiments/scientific_study/metrics_engine.py`: Lines 80–129, Lines 169–170
- **File:** `od_experiments/scientific_study/study_runner.py`: Lines 172–174

```python
167:         "skill_score_vs_persistence": round(skill_score, 4),
168:         "mean_bias": round(mbe, 4),
169:         "acc": round(tac, 4),  # Maintained for backwards-compatibility
170:         "tac": round(tac, 4),  # Explicit Tendency Anomaly Correlation
171:     }
```

#### Mechanism of Failure
1. **Mathematical Distinction:**
   - In operational meteorology (WMO, ECMWF, NOAA), the Anomaly Correlation Coefficient ($\text{ACC}$) evaluates spatial pattern correlation of departures from a **multi-decadal climatological mean** ($\bar{C}_{\text{clim}}$):
     $$\text{ACC} = \frac{\sum_{i,j} w_j [f_{i,j} - \bar{C}_{i,j}] [y_{i,j} - \bar{C}_{i,j}]}{\sqrt{\sum_{i,j} w_j [f_{i,j} - \bar{C}_{i,j}]^2 \sum_{i,j} w_j [y_{i,j} - \bar{C}_{i,j}]^2}}$$
     The universally recognized **$0.60$ threshold** (Hollingsworth et al., 1980) defines the synoptic boundary of operational utility for $500\text{ hPa}$ geopotential height ($Z_{500}$) climatological anomalies.
   - Tendency Anomaly Correlation ($\text{TAC}$) evaluates departures relative to the **initial state** $x_0 = X(t_0)$:
     $$\text{TAC} = \frac{\sum_{i,j} w_j [f_{i,j} - x_{0,i,j}] [y_{i,j} - x_{0,i,j}]}{\sqrt{\sum_{i,j} w_j [f_{i,j} - x_{0,i,j}]^2 \sum_{i,j} w_j [y_{i,j} - x_{0,i,j}]^2}}$$
2. In `metrics_engine.py`, the code computed $\text{TAC}$ and aliased `"acc": round(tac, 4)`.
3. In `study_runner.py` and `scientific_study_v2.tex`, this value ($0.959$) was compared directly against the WMO $0.60$ synoptic utility cutoff. Because 24-hour surface temperature tendencies are strongly dominated by the diurnal cycle and local inertia, $\text{TAC}$ values are inherently higher and have completely different variance characteristics than climatological $\text{ACC}$. Conflating them is scientifically invalid.
