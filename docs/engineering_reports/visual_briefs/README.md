## 🛠️ Verification & Compilation Protocol

All briefs are authored in LaTeX using standard packages (`lmodern`, `geometry`, `tcolorbox`, `tabularx`, `booktabs`, `enumitem`, `hyperref`) and compiled with `pdflatex`:
```powershell
cd docs/engineering_reports/visual_briefs
Get-ChildItem -Filter "BRIEF_*.tex" | ForEach-Object { pdflatex -interaction=nonstopmode $_.Name }
```

Every brief strictly respects the single-page boundary, verified via automated Python PDF page inspection (`len(reader.pages) == 1`).
